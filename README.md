# Shakespeare: a long reading

A long-term project to read the whole of Shakespeare and work out, from the text alone, what it observes about being human.

No outside criticism or commentary is used. Every claim should trace to lines in the corpus.

## Layout

- `corpus/complete-works.txt` — the Project Gutenberg plain-text Complete Works (ebook #100), unmodified.
- `corpus/works/` — the same text split into one file per play or poem, numbered in the Gutenberg order.
- `notes/` — reading notes, one file per work. Each records what happens, what the work observes about being human (with act.scene citations), what it teaches, lines worth keeping, and the work's recurring preoccupations.
- `THE-HUMAN-CONDITION.md` — the synthesis: what the corpus as a whole observes and what it teaches, written for one reader to digest and argue with.

## How to use it

Read the synthesis first. When a claim there seems wrong or too neat, go to the notes for the play, then to the play itself. The notes cite act and scene so the text is always a few steps away.
